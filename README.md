# Snap & Study 📚

### Snap it. Understand it. Study smarter. 📸📚

Snap & Study is an AI-powered study assistant that helps students understand confusing questions, diagrams, problems, and notes using simple, beginner-friendly explanations.

Users can type a question or upload a photo of their study material. The AI analyzes it and provides a clear, step-by-step explanation. Students can also send their study explanation to their email for later revision.

---

## 🚀 Features

- 📸 Upload photos of questions, diagrams, and notes
- 💬 Ask study questions using text
- 🤖 AI-powered explanations using Google Gemini
- 📚 Beginner-friendly, step-by-step explanations
- 🧠 Identifies important concepts and formulas
- 📧 Send study explanations to email
- 🔐 API keys and email credentials are kept private using Streamlit secrets

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP
- Git & GitHub
